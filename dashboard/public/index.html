    H.A.L.O. creates a ready-made pipeline database in your Notion — no manual fields.

    1. Open Notion → My integrations and create an internal integration named H.A.L.O.
    2. Copy the Internal Integration Secret and paste it below.
    3. In Notion, open the page where you want the CRM → ⋯ → Connections → add H.A.L.O.

    Connect your CRM

    One wizard: run SQL once in Supabase, then paste credentials here.

    Step 1 — Create table in Supabase

    1. Create a project at supabase.com/dashboard → New project.
    2. Open SQL Editor → New query (pick your project first).
    3. Click Copy SQL below, paste into the editor, then click Run. This creates the leads table (required — without it connect will fail).
    Loading schema…

    Safe to re-run. Without this SQL, H.A.L.O. cannot store leads.

    Step 2 — Paste API credentials

    1. Open Project Settings → API.
    2. Copy Project URL and the secret service_role key (not the anon key).

    Step 3 — Finish

    Credentials verified and leads table found. Click Connect CRM to save them on the server and open the pipeline.
